# 高光谱图像分类

## 介绍
本仓库为2024秋软件工程理论高光谱图像分类的项目分享仓库

## 任务主题  
使用 Django 框架开发一个高光谱图像分类 WEB 应用。

## 作业目标  
1. 构建一个功能完善的 WEB 系统，实现以下功能：  
   - 用户上传高光谱图像。  
   - 系统调用深度学习模型，返回地物分类结果。  
   - 结果可视化并支持下载分类图像。  
2. 学习 Django 开发流程并掌握项目部署方法。

## 工具与技术栈  

### 编程语言  
- **Python**：用于后端开发与深度学习模型。  
- **HTML/CSS/JavaScript**：用于前端页面设计。

### 框架与库  
- **后端**：Django（WEB 框架）。  
- **前端**：Bootstrap 或其他前端框架（提升界面美观）。  
- **深度学习**：PyTorch 或 TensorFlow（训练与加载模型）。  

### 其他工具  
- **数据处理**：NumPy、Pandas。  
- **数据可视化**：Matplotlib、Seaborn。  
- **部署平台**：云服务器。

 

## 任务分配  
- **模型部分**：负责训练、优化和保存深度学习模型。  
- **后端部分**：负责 Django 项目搭建、路由设计和 API 实现。  
- **前端部分**：设计简洁易用的上传和结果展示页面。  
- **测试与部署**：测试功能，优化性能，并将系统上线。
